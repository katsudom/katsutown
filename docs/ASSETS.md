# Generated assets

Everything under `public/assets/` is generated by `npm run assets` (see
`tools/generate-assets.mjs`), which draws every PNG pixel-by-pixel from
`src/game/palette.json`. The files are safe to overwrite: re-running the script
regenerates them identically.

## Swapping in a CC0 art pack

Replace the PNGs at the same paths with images of the same size (see
`src/game/assets.ts` for the manifest). No code changes are required.

`npm run dev` and `npm run build` run the generator first (the `predev` and
`prebuild` hooks in `package.json`), which would overwrite hand-made art.
Anyone swapping in hand-made art must remove those hooks first.

# Katsudom Town

A browser-based, top-down pixel-RPG that doubles as the portfolio of
**Dominic Pham** — Computer Science @ the University of Oklahoma.

Walk around a small college town. The buildings, signs and townsfolk are the
résumé: four project buildings ring the square, the Hacklahoma Clubhouse is
north, and the Campus Gate is east. A plain, fast version of the same content
lives at `/classic` for anyone who would rather just read.

## Quick start

```bash
npm install
npm run dev
```

Then open the printed localhost URL. `npm run dev` regenerates the pixel art
first, so a fresh clone needs no extra steps.

## Scripts

| Script                 | What it does                                             |
| ---------------------- | -------------------------------------------------------- |
| `npm run dev`          | Generate assets, then start the Vite dev server          |
| `npm run build`        | Generate assets, typecheck, and emit a static `dist/`    |
| `npm run preview`      | Serve the built `dist/` locally, at the deploy base path |
| `npm run assets`       | Redraw every PNG and the bitmap font from scratch        |
| `npm run lint`         | ESLint over the whole project, zero warnings allowed     |
| `npm run format`       | Prettier write                                           |
| `npm run format:check` | Prettier check                                           |

## Controls

|          | Keyboard               | Touch           |
| -------- | ---------------------- | --------------- |
| Move     | Arrow keys or **WASD** | On-screen D-pad |
| Interact | **Space** or **Enter** | **A** button    |
| Menu     | **Esc**                | Menu button     |

The menu holds the profile, a skills "inventory", a quest log, a fast-travel
mini-map, a sound toggle, and an exit to the classic portfolio.

## How it is put together

- **Phaser 3** + **TypeScript**, bundled by **Vite** as a two-page static site:
  `index.html` is the game, `classic.html` is the plain React + Tailwind page.
- **16×16 tiles rendered at 3×**, pixel-perfect, with grid-locked movement.
- **All art is generated.** `tools/generate-assets.mjs` draws every tile,
  character, building, prop, UI frame and even the bitmap font pixel by pixel
  from the palette in `src/game/palette.json`. Nothing is downloaded, and the
  art is original — drawn in the classic GBA-era top-down RPG style rather than
  copied from any existing game.
- **All audio is synthesised** at runtime through the Web Audio API — original
  chiptune loops and blips, so no audio files ship either.
- **All portfolio copy lives in one file**, `src/game/data/content.ts`, and both
  the game and the classic page render from it. The two versions cannot drift.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the full contract: scene
graph, system APIs, tilemap layer conventions and the asset manifest.

## Swapping the art

Every image is regenerated by `npm run assets` into `public/assets/`. To use a
different (for example CC0) art pack instead, replace the PNGs at the same paths
with same-sized images — the manifest in `src/game/assets.ts` lists every path
and its exact dimensions. No code changes needed.

## Deploying

The build is a static site with no backend.

```bash
# GitHub Pages project site (default): served from https://<user>.github.io/<repo>/
npm run build

# Root or custom domain
BASE_PATH=/ npm run build
```

`BASE_PATH` sets Vite's `base`; it defaults to `/katsutown/`, matching the
repository name. Change it to
match your repository name, or set it to `/` for a root deployment. Upload
`dist/` to any static host.

To check the built site locally, `npm run preview` serves it at the same base
path the build used — so with the default it lives at
`http://localhost:4173/katsutown/`, not at the root. The dev server is
unaffected and always serves from `/`.

## Project layout

```
tools/generate-assets.mjs   draws every PNG + the bitmap font
public/assets/              generated art (safe to delete and regenerate)
src/main.ts                 Phaser bootstrap
src/game/config.ts          tile size, render scale, scene keys, depths
src/game/palette.json       the one place colours are defined
src/game/assets.ts          asset manifest (paths + exact sizes)
src/game/data/content.ts    all portfolio copy
src/game/data/maps.ts       per-map NPCs, interactables and warps
src/game/scenes/            Boot, Title, Ui, World, Menu
src/game/systems/           input, player, audio, dialogue, touch, settings
src/classic/                the plain React + Tailwind portfolio
docs/ARCHITECTURE.md        the build contract
```
